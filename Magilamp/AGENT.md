# Agent Guide

## General rules

- Think before acting. Read existing files before writing code.
- Be concise in output but thorough in reasoning.
- Prefer editing over rewriting whole files.
- Do not re-read files you have already read.
- Test your code before declaring done.
- No sycophantic openers or closing fluff.
- Keep solutions simple and direct.

The overall project aims to be very compact (*less is more* mantra)

The project si an Arduion R4 WIFI based project, based on FreeRTOS library
Pin 2 is connected to a piezo speaker to produce sound using arduino tone() functions
